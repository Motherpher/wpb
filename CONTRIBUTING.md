# Contributing

## Adding a work
1. Find the strongest available primary source.
2. Confirm the byline.
3. Record exact title and date where available.
4. Add the work to `data/corpus.json`.
5. Assign an evidence grade.
6. Add themes conservatively.
7. Add the primary source to `sources/source-registry.md`.
8. Do not paste full copyrighted text.

## Corrections
Use a commit message that states what changed and why.

## Uncertain material
Add it to `sources/unresolved-records.md` rather than forcing it into the canonical corpus.
