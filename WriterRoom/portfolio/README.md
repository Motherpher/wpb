# WriterRoom Portfolio Layer

The portfolio is a curated public-facing layer built from approved Profile Core claims and the broader WriterRoom archive.

## Rule

The archive answers **what work exists**. The portfolio answers **what should represent Weronika now**.

## Portfolio states

- `hidden`
- `eligible`
- `selected`
- `featured`

## Optional public fields

- public summary;
- translated summary;
- display title;
- hero image;
- image-rights status;
- excerpt-rights status;
- theme tags;
- display order.

## Public site relationship

The public site should consume approved portfolio data and approved Profile Core material. CareerHub state is not a public-site source.

## Rights

No full-text republication or image use should be inferred from the existence of an archive record. Rights/permission must be explicit where required.
