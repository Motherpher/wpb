# WriterRoom Publication Desk

The Publication Desk converts accepted/published work into durable publication records.

## Publication record

A publication record may include:

- final title;
- original title;
- translated title;
- publication/outlet;
- publication date;
- URL and archive URL;
- byline/role;
- language;
- format;
- editor and other credits where evidenced;
- rights/reproduction notes;
- DOI or catalogue identifier where applicable;
- portfolio eligibility;
- evidence/provenance.

## Flow

`Published → Archive record → Portfolio review → optional Career evidence export`

Publication does not automatically mean portfolio selection or CareerHub eligibility.

## Archive compatibility

For now, canonical historical publication data remains in the existing root-level archive estate (`../data`, `../bibliography`, `../sources`, etc.). This desk defines ownership and future workflow; it does not relocate those files yet.
