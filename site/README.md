# Site layer — reserved

No frontend framework is committed yet.

This directory is intentionally reserved for the future portfolio site. The site should **consume** the archive's canonical content rather than duplicate it.

Source layers:
- `../data/corpus.json`
- `../data/themes.json`
- `../content/`

Do not add a framework until:
1. public portfolio scope is agreed,
2. featured works are selected,
3. visual identity is defined,
4. rights for images/excerpts are clear.

The repository should remain useful even if the site framework is later replaced.
