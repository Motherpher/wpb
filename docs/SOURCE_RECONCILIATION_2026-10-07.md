## Data rule going forward

A candidate moves into the public catalog only when the source establishes all three minimum fields: **work identity**, **Weronika identity**, and **credit role**. A source hub, tag page, search result or name association may strengthen discovery but cannot by itself create a new public portfolio item. Multiple editions, republications, translations of the same credit, archive mirrors and reviews remain attached evidence rather than duplicate works.
