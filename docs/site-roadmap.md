# Future portfolio site roadmap

The repository should remain the source of truth even after a public site is launched.

## Stage 0 — archive foundation
- verified corpus
- evidence model
- thematic taxonomy
- writer profile
- selected-work notes
- unresolved-record queue

## Stage 1 — portfolio content
- final public biography
- 6–10 selected works
- excerpt permissions / publisher-use review
- authorised portrait and project imagery
- contact/representation copy
- language and geography filters

## Stage 2 — implementation
Recommended architecture: static-first site consuming Markdown + JSON from this repository. Keep framework choice open until visual direction is defined.

Important requirements:
- fast archive filtering
- strong typography for long-form work
- original-language titles preserved
- optional translated titles/summaries
- structured metadata for SEO
- accessible and mobile-first
- no full-text republication without rights

## Stage 3 — archive enhancement
- archived URLs for link rot
- publication screenshots where legally appropriate
- richer chronology
- interviews / talks / audio / film credits
- citation export
- per-work research notes

## Separation rule
The public portfolio should be selective. The research archive should remain comprehensive and transparent.
