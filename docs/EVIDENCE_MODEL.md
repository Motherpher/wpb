# Evidence model

The repository separates **authorship**, **professional context** and **unresolved association**.

## A — Verified authorship
Use when a primary publication record supports authorship: direct byline, publisher author page, journal metadata, book catalogue or equivalent.

## B — Verified contextual/professional record
Use for employment, press-office work, academic affiliation, translation, event roles or other records that establish context but not authorship of a specific work.

## C — Unresolved/provisional association
Use when a name is connected to a work or role but the precise relationship is not yet sufficiently established.

## Rules

- Do not upgrade B or C to A from search snippets alone when a direct publication record can reasonably be sought.
- Keep publication facts separate from repository interpretation.
- Preserve uncertainty explicitly.
- Prefer original publisher URLs; where only archive/tag pages survive, say so.
- A missing date is better than an invented date.
- Do not infer personal identity characteristics from themes, family references or surname.
