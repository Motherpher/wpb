# WriterRoom → CareerHub Evidence Bridge

This bridge is the only sanctioned cross-room path from WriterRoom into CareerHub.

It is an **explicit evidence export**, not shared storage.

## Permitted classes

- verified publication records;
- selected work;
- confirmed biography statements;
- verified professional capabilities;
- approved portfolio links/descriptions.

## Prohibited automatic export

- unpublished drafts;
- confidential or protected-source material;
- interview notes;
- private research notes;
- unresolved archive records;
- private editorial comments;
- personal material unrelated to a career-use case.

## Rule

Every exported item retains original provenance, evidence state and approval scope. CareerHub may reframe evidence for a vacancy but may not strengthen or change the underlying factual claim.

See `export.yaml` for the machine-readable contract.
